# 📊 Bank Marketing Campaign Performance Analysis

## 📌 Project Overview
This project analyzes a bank's marketing campaign data using Microsoft Power BI to understand customer subscription behavior and campaign effectiveness.

The dashboard provides insights into subscription outcomes, customer occupations, contact methods, age groups, and education levels.

## 🎯 Objectives
- Analyze the overall success rate of the marketing campaign.
- Understand subscription patterns across customer occupations.
- Compare subscription rates by contact method.
- Explore subscription behavior across different age groups.
- Examine customer distribution by education level.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query for data transformation
- DAX for calculated columns and measures
- Data visualization and analysis

## 📂 Dataset
**Dataset:** Bank Marketing Dataset  
**Source:** UCI Machine Learning Repository  
**Records analyzed:** 41,188  
**Target variable:** `y` — whether the customer subscribed to a term deposit (`yes` or `no`).

## 📈 Dashboard Highlights
- **Total Customers:** 41,188
- **Successful Subscriptions:** 4,640
- **Subscription Rate:** 11.27%

### Visualizations
1. Subscription Rate by Occupation
2. Subscription Rate by Contact Method
3. Subscription Rate by Age Group
4. Subscription Outcome
5. Customers by Education Level

## 🔍 Key Findings
- The overall subscription rate is approximately 11.27%.
- Most customers did not subscribe to the term deposit.
- Subscription rates differ across occupations and contact methods.
- The age-group visualization helps compare subscription rates across customer age segments.
- Education-level analysis shows the distribution of customers across education categories.
